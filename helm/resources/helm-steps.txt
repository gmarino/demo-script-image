-- Se non parte: reset dei componenti Kubernetes (non distrugge il cluster):

minikube ssh
sudo systemctl restart kubelet
sudo systemctl restart docker
exit
minikube start --wait=all
---------------------------------------------------------------------------------------------
-- Se ancora non parte: fix definitivo con re-create del cluster
minikube delete --purge
minikube start --driver=docker --memory=4096 --cpus=2 --wait=all --wait-timeout=6m

---------------------------------------------------------------------------------------------
-- Aggiornamento Helm chart
---------------------------------------------------------------------------------------------
1. Aggiorna il chart:
--> helm upgrade --install demo ./helm-chart
---------------------------------------------------------------------------------------------
2. Controlla i pod finché il gateway non diventa Ready:
--> kubectl get pods -l app=demo-gateway-service
e
--> kubectl describe pod -l app=demo-gateway-service | grep -nE 'Readiness|Liveness|Events'
---------------------------------------------------------------------------------------------
3. Verifica gli endpoint del Service (devono comparire IP:8080):
--> Kubectl get endpoints demo-gateway-service
---------------------------------------------------------------------------------------------
4. Prova l’ingress:
--> curl http://demo.local/actuator/health
